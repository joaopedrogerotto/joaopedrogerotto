## 👋 Sobre mim

Olá! Eu sou o João Pedro Gerotto Fernandes, mais conhecido como **JP**. Sou natural de Presidente Prudente/SP e hoje moro em Mogi das Cruzes/SP. Sou formado em **Análise e Desenvolvimento de Sistemas pela FATEC Mogi das Cruzes**.

Atualmente atuo no **Back-End com C#, .NET e SQL Server**, criando e mantendo APIs, e no **Front-End com React e TypeScript**. Gosto de entregar soluções de ponta a ponta: do modelo de dados à interface que o usuário final usa.
